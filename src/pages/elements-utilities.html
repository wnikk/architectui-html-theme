Bootstrap Helpers

All Bootstrap 6 helper classes available in the official Bootstrap documentation are also available in ArchitectUI Framework: Spacing, resets, typography utilities, sizing and others.

Theme Helpers
.aui-animate-light-speed-in … .aui-animate-spin Animations: light-speed-in, flip, pulse, fade-in, spin
.aui-icon-gradient-<color> Gradient stroke for Lucide icons
.aui-scroll + .aui-scroll-sm … .aui-scroll-lg Scroll area with a fixed height
.aui-chart, .aui-map Height containers for Chart.js and Leaflet
