Bootstrap Helpers

All Bootstrap 5 helper classes available in the official Bootstrap documentation are also available in ArchitectUI Framework: Spacing, resets, typography utilities, sizing and others.

Theme Helpers
.opacity-0 … .opacity-100 Bootstrap opacity utilities: 0%, 25%, 50%, 75%, 100%
.aui-opacity-60 … .aui-opacity-90 Theme additions: 60%, 70%, 80%, 90%
.aui-fs-1 … .aui-fs-4 Theme font sizes: 0.95rem, 1.3rem, 1.6rem, 2rem
.aui-divider Thin horizontal separator with theme spacing
