How to use the colors

Use the Bootstrap color classes. Every theme gives them its own values, in both modes, so the markup stays the same when the theme changes.

theme-primary badge-subtle badge-outline theme-success theme-warning theme-danger theme-focus theme-accent
fg-primary fg-danger fg-2
  • theme-<color> on a component (button, badge, alert, table, accordion, avatar) — the color with the text that reads on it.
  • bg-<color> with fg-contrast-<color> — the theme gradient over the color (widgets, progress bars) and a readable text.
  • bg-subtle-<color>, fg-emphasis-<color>, border-subtle-<color> — pale backgrounds with dark text, for notes and statuses.
  • fg-<color>, border-<color>, shadow-<color>, btn-solid, btn-outline, btn-subtle, btn-text with theme-<color>.
  • Surfaces and text: bg-body, bg-1, bg-2, bg-3, fg-body, fg-1, fg-2, fg-3, border.
  • Colors: primary, accent, secondary, success, info, warning, danger, inverse from Bootstrap 6; focus from the theme.
<span class="badge theme-primary">New</span>
<div class="card bg-primary fg-white">...</div>
<div class="alert theme-warning">...</div>
<p class="bg-subtle-success fg-emphasis-success p-3">Saved</p>
<button class="btn-outline theme-primary">Edit</button>
<a class="fg-primary" href="#">Details</a>

For your own styles, read the colors from CSS variables instead of writing HEX values: a variable follows the theme and the dark mode, a fixed value does not.

A panel on theme variables
Its surface, border, text and shadow come from the current theme. Switch the theme in the header to see it change.
  • var(--bs-<color>-base) for the color and color-mix(in srgb, var(--bs-<color>-base) 50%, transparent) for transparency.
  • Nine tokens of every color: -base, -bg, -fg, -fg-emphasis, -bg-subtle, -bg-muted, -border, -focus-ring, -contrast.
  • Surfaces: --aui-app-bg (page), --bs-bg-body (cards), --bs-bg-1, --bs-bg-2, --bs-bg-3, --bs-border-color.
  • Text: --bs-fg-body, --bs-fg-1, --bs-fg-2, --bs-fg-3, --bs-link-color.
  • Gradients: --aui-gradient-<color>.
  • Override a value in your stylesheet loaded after the theme: for every theme in :root, for one theme in [data-aui-theme="<id>"]. Write both modes in one value with light-dark(), as Bootstrap 6 does.
.order-panel {
  background: var(--bs-bg-body);
  color: var(--bs-fg-body);
  border: 1px solid var(--bs-border-color);
  box-shadow: 0 .5rem 1rem color-mix(in srgb, var(--bs-primary-base) 15%, transparent);
}

.order-panel h3 {
  color: var(--bs-primary-fg-emphasis);
}

/* Your brand color in every theme, both modes */
:root {
  --aui-brand-solid: #3f6ad8;
  --aui-brand-text: light-dark(#3f6ad8, #8fb0f0);
}

/* Only in Coffee: a darker surface in the dark mode */
[data-aui-theme="coffee"] {
  --aui-surface: light-dark(#fff, #2b201b);
}

Scripts read the same variables through ArchitectUI. Read them when you draw, and again after aui:theme-change: the theme or the mode may change while the page is open.

token("primary")
 
token("--aui-surface")
 
rgba("primary", .25)
 
theme-change events
0
  • ArchitectUI.token(name) — the color of a theme color (--bs-<name>-base) or the value of --bs-<name> as #rrggbb; a name that starts with -- is read as is.
  • ArchitectUI.rgba(name, alpha) — the color with transparency.
  • ArchitectUI.chartDefaults(Chart) — fonts, text and grid colors of the theme for Chart.js.
  • The event aui:theme-change on document fires after a theme or mode change.
const { token, rgba, chartDefaults } = window.ArchitectUI;

chartDefaults(Chart);
const chart = new Chart(canvas, {
  type: "line",
  data: { labels, datasets: [{
    data: values,
    borderColor: token("primary"),
    backgroundColor: rgba("primary", .15),
  }] },
});

document.addEventListener("aui:theme-change", () => {
  chartDefaults(Chart);
  chart.data.datasets[0].borderColor = token("primary");
  chart.data.datasets[0].backgroundColor = rgba("primary", .15);
  chart.update();
});
